# RF do INPE

**Não é obrigatório colocar nada aqui.** Se a pasta estiver vazia, o programa baixa
automaticamente os arquivos diários do dataserver do INPE
(`riscofogo_meteorologia/observado/risco_fogo/AAAA/`), recorta para o Paraguai e guarda em cache.

Se preferir enviar os arquivos (ou se o download automático falhar), coloque aqui os
`INPE_FireRiskModel_2.2_FireRisk_AAAAMMDD.nc`. Atenção: o GitHub aceita no máximo
25 MB por arquivo pelo navegador; os arquivos do INPE têm ~9 MB cada.
